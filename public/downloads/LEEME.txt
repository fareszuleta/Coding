NEXO 0.1.0 — CLI DE DEMOSTRACIÓN

Requisito: Node.js 18 o posterior.

1. Extrae el ZIP.
2. Abre una terminal en la carpeta que contiene nexo.mjs.
3. Comprueba la versión:
   node nexo.mjs --version
4. Consulta tu entorno:
   node nexo.mjs doctor
5. Ejecuta el ejemplo:
   node nexo.mjs demo

Ayuda: node nexo.mjs --help

La CLI solo imprime información y ejemplos. No escribe archivos,
ejecuta otros procesos, instala paquetes ni se conecta a Internet.
El árbol de proyecto mostrado es ilustrativo.

Para eliminar la demo, borra esta carpeta.
Puedes leer el archivo nexo.mjs con cualquier editor de texto.
