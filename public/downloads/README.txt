NEXO 0.1.0 — DEMO CLI

Requirement: Node.js 18 or later.

1. Extract the ZIP.
2. Open a terminal in the folder containing nexo.mjs.
3. Check the version:
   node nexo.mjs --version
4. Check your environment:
   node nexo.mjs doctor
5. Run the example:
   node nexo.mjs demo

Help: node nexo.mjs --help

The CLI only prints information and examples. It does not write files,
run other processes, install packages, or connect to the Internet.
The project tree shown in the demo is illustrative.

To remove the demo, delete this folder.
You can read nexo.mjs in any text editor.
