GUÍA RÁPIDA

Un buen lugar para empezar.

Nexo es una plataforma ficticia con una CLI funcional de demostración. El programa incluido imprime información y ejemplos en la terminal.

¿Qué necesito para usar la demo?

Node.js 18 o posterior. Descarga el ZIP, extrae sus archivos y abre una terminal dentro de la carpeta que contiene nexo.mjs.

¿Qué es una CLI?

Es un programa que utilizas escribiendo comandos en una terminal. En esta demo, node ejecuta el archivo nexo.mjs y el último argumento elige la acción.

¿Qué contiene la descarga?

El código fuente nexo.mjs y un archivo LEEME.txt. No necesita paquetes adicionales, permisos de administrador ni una cuenta.

¿Cómo funciona el botón Copiar?

Copia el texto exacto del bloque visible. Si el navegador no permite copiar, selecciona el comando y usa la función de copia de tu sistema. Puedes revisar el texto pegándolo primero en un editor.

La terminal dice que no encuentra «node».

Comprueba que Node.js esté instalado y disponible en tu terminal. Puedes usar el playground para explorar la salida de ejemplo sin instalar nada.

¿Cómo elimino la demo?

Elimina la carpeta extraída. La CLI no modifica la configuración del sistema. El progreso de la guía se puede reiniciar desde Preferencias.
