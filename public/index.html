QUICK GUIDE

A good place to start.

Nexo is a fictional platform with a working demo CLI. The included program prints information and examples in your terminal.

What do I need to use the demo?

Node.js 18 or later. Download the ZIP, extract its files, and open a terminal in the folder containing nexo.mjs.

What is a CLI?

It is a program you use by typing commands in a terminal. In this demo, node runs the file nexo.mjs and the last argument selects the action.

What is included in the download?

The source file nexo.mjs and a README.txt file. No extra packages, administrator permissions, or account are needed.

How does the Copy button work?

It copies the exact text of the visible block. If your browser does not allow copying, select the command and use your system copy shortcut. You can review it by pasting it into a text editor first.

My terminal cannot find “node.”

Check that Node.js is installed and available in your terminal. You can use the playground to explore sample output without installing anything.

How do I remove the demo?

Delete the extracted folder. The CLI does not change your system settings. You can reset the guide progress in Preferences.
